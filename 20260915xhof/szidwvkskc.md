# 1一6个月新生儿奶量表中各时间段标准分别是多少？

> 更新时间：2026-09-15 (UTC+8)

我家大宝出生一个月了，现在每天大概要喝6、7次奶，每次大概能吃到120毫升左右，邻居家的小朋友也差不多一个月，聊天的时候发现，他家的小朋友一顿吃奶可以吃150毫升，想问一下我家宝宝的吃奶量是不是太少了，想问问姐妹们有没有新生儿奶量表啊？ 
查看全部内容

根绝新生儿奶表表可以看出新生儿的奶量标准取决于婴儿的月龄和体重，月龄不同，体重不一样，吃奶量也会不同。刚出生的婴儿每天能吃6-8次奶，奶量在30毫升左右，出生一个月婴儿一天大概要喂6-7次奶，奶量在80毫升左右，根据婴儿的消化能力和体重增长的情况，吃奶次会慢慢减少，奶量会逐渐增加，到了6个月左右婴儿一天大概吃3顿奶，奶量在200毫升左右。

根据新生儿奶量表可以看出，宝宝在6个月左右喝奶次数会减少，奶量会增加，这个时候可以开始用辅食来代替一顿奶，接下来给大家介绍下1-6个月新生儿的奶量标准：

- 1. 刚出生的婴儿，一天一般喂6-7次奶，每次奶量在30毫升左右，每次间隔3-4个小时；
- 2. 婴儿足月时按需求喂养，婴儿能吃多少就喂多少，一般每天喂6-7次奶，每次间隔3-4各小时，每餐应该吃80毫升左右；
- 3. 婴儿2-3个月时的喂奶量应该增加到每顿150毫升左右,每天喂5-6次，每次应间隔4小时左右；
- 4. 3-6个月的婴儿可以按照2-3个月的婴儿奶量进行喂养，到5-6个月时可以增加奶量到每顿200毫升左右；
- 5. 6个月每次吃奶量应该200-250毫升，每隔4小时喂一次奶，一天三顿，可以用辅食代替一顿奶。
新手父母喂奶时不用完全按照奶量表给宝宝喂奶，强行喂奶的话可能会导致宝宝出现厌奶的情况，在宝宝吃饱后可以将乳房里充盈的乳汁用吸奶器吸出来，让乳房排空。
