# 精漏打疫苗或影响入学！最全宝宝疫苗接种时间表来了，开学前赶紧自查

> 更新时间：2026-09-11 (UTC+8)

毕业季结束，宝爸宝妈们即将迎来孩子的开学季，入托、入学前的预防接种各位家长是否已经拿出“小绿本”给孩子检查过有没有遗漏的疫苗接种呢？

《疫苗流通和预防接种管理条例》中第二十七条表明：“儿童入托、入学时，托幼机构、学校应当查验预防接种证，发现未依照国家免疫规划受种的儿童，应当向所在地的县级疾病预防控制机构或者儿童居住地承担预防接种工作的接种单位报告，并配合疾病预防控制机构或者接种单位督促其监护人在儿童入托、入学后及时到接种单位补种。”

为什么孩子从一出生就开始接种疫苗呢、为孩子接种疫苗的具体时间、接种疫苗有哪些注意事项是我们今天为开学季做准备的话题。

为什么需要接种疫苗

为孩子接种疫苗不单单是因为国家相关法律法规规定。对宝宝来说，健康时期接种疫苗在身体内，不发病的前提下，会在孩子的身体中产生抗体，从而获得特异性免疫。

严格按照合理程序实施疫苗接种（接种的疫苗属于正规生产的疫苗都属于极低风险制品），才能发挥疫苗的免疫效果，便能促使孩子获得高度的免疫水平，逐渐建立自己完善的免疫屏障，可以有效的控制传染病的流行。

接种疫苗时间

疫苗可分为两类：一类疫苗（计划内疫苗）和二类疫苗（计划外疫苗）。下面我们一起看一下疫苗具体的接种时间。

一类疫苗

小编为父母准备了一份从孩子出生至12周岁需要接种疫苗的时刻表

二类疫苗

水痘疫苗：1~12岁的儿童适合接种，1岁以上可接种第一针，4~6岁时建议接种第二针加强。

B型流感嗜血杆菌疫苗：2、4、6个月时各接种一针，1岁后接种一针即可。

流行性感冒疫苗：世界卫生组织建议6个月以上，5岁以下的孩子优先接种流感疫苗。第一针与第二针间隔时间为4周，在流行之前（9~10月份）是最佳接种时间。

手足口病疫苗：即预防肠道病毒71型的疫苗，适合6个月至3岁易感婴幼儿。

轮状病毒疫苗：接种对象为2个月~3岁的孩子，是一种口服疫苗。

接种疫苗的注意事项

有许多家长会担心孩子因为身体或其他原因延迟接种疫苗而担心无法入学，故而在孩子没开学前想急忙给孩子补种，但接种疫苗也是有很多需要注意的地方。下面一起看一下接种疫苗前和接种疫苗后有哪些注意事项。

接种疫苗前

1.宝宝出生时医生会给一本《预防接种证》（一般为绿颜色的疫苗接种记录本，地域差异会有大的或小的疫苗接种记录本），或在孩子出生后1个月内至家里附近的社区卫生服务中心/乡镇卫生院领取。一般《预防接种证》上会有详细的宝宝接种的疫苗和接种时间，父母需按照规定的程序和时间带宝宝去就近地点接种，接种时记得带上《预防接种证》，接种完成后医生会为孩子记录接种日期以及接种疫苗的批次。

2. 预防接种的前一天为宝宝洗个香喷喷的澡，接种当天记得给宝宝穿着清洁宽松，并且可以遮盖接种部位的衣物，既便于医生给宝宝接种疫苗，也能在接种后避免细菌感染。

3. 接种当天，主动与预检的医生说明孩子目前的健康状况，若宝宝有任何身体不适，例如：感冒、发烧、皮肤等疾病，需及时告知医生并且暂缓接种疫苗。

接种疫苗后

1.接种疫苗分为口服和注射。若是注射接种疫苗，家长需将宝宝的双手固定，以防止宝宝在接种过程中乱动，可用其他事物来分散孩子的注意力。

2. 接种疫苗后棉签按压针眼几分钟不出血便可将棉签拿开，接种的部位切不可搓揉。接种完毕后，需在留观区域休息30分钟。若孩子出现不良反应时立即请医生给宝宝查看。

3. 接种后让宝宝得到充分的休息，多喝水，注意孩子的冷暖，防止其他疾病的发生。

4. 接种疫苗的当天不要给孩子洗澡，保持接种部位的清洁，防止局部感染。

5. 接种疫苗后若孩子出现轻微的发热、烦躁、哭闹、甚至食欲不振等情况时，父母不必过于担心，一般这些症状几天内便会消失。但若孩子持续以上现象时间较长并且反应强烈时，需立即带孩子就医确诊。
